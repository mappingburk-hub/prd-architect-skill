# Contributing to PRD Architect Skill

Thank you for your interest in improving **PRD Architect Skill**! Contributions such as new language translations, AI platform adapters, domain-specific PRD modules (e.g., SaaS, mobile games, AI apps), and template refinements are welcome.

## How to Contribute

1. **Fork** this repository and create a new branch from `main`:
   ```bash
   git checkout -b feat/your-improvement
   ```
2. **Make your changes:**
   - Keep `skills/prd-architect-en/SKILL.md` and `skills/prd-architect-id/SKILL.md` in sync whenever updating core workflow rules or sections.
   - Maintain clear, measurable, and unambiguous prompt language.
   - Ensure YAML frontmatter remains valid (`name` and `description` fields required).
3. **Commit** with clear, descriptive messages (Conventional Commits preferred, e.g., `feat: add Japanese SKILL.md`, `docs: improve Cursor setup instructions`).
4. **Open a Pull Request** describing what you changed and why.

## Code of Conduct
Be respectful, constructive, and concise in issues, discussions, and pull request reviews.
